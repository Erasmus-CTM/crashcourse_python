Datetime objects as indices

It is very common that the index contains information about the date and the time of a given measurement as a string. In Sweden we use a format yy-mm-dd hh:mm:ss to report the time of a measurement as a string. ### Example: Temperature meassurements

Datetime objects as indices (cont.)

We often want to make simple arithmetic with date and time information for this end the list of strings has to be converted in a list of so-called datetime objects first

This way we can easlily find out how much time passed between the measurements AF.index[1]-AF.index[0]. The result is a timedelta object displayed here as Timedelta(’0 days 14:29:00’)

In the example power is updated every minute, price is updated every hour, rate is updated every day.

What can be done?

Use frame methods like: dropna, ffill, bfill or interpolate.

Missing data (2/2)

Let’s use ffill and bfill to pad missing values.

  • ffill: Fill NA/NaN values by propagating the last valid observation to next valid.
  • bfill: Fill NA/NaN values by using the next valid observation to fill the gap.
